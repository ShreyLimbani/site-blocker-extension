## Feature options:

- *Productivity Stats* - Track blocked sites and time spent
- *Password Protection* - Prevent easy override of blocks
- *Focus Mode* - Block all sites except whitelist
- *Smart Scheduling* - Block sites only during work hours
- *Whitelist* - Allow certain sites always
- *Break Reminders* - Suggest breaks after focused work
- *Dark Mode* - Toggle for extension UI
- *Daily Limits* - Maximum override time per day
- *Custom Messages* - Personalized blocking messages
- *History/Reports* - Track blocking patterns
